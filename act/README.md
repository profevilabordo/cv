# Carpeta de Actividades y TPs Extra
Subí acá los archivos PDF que quieras compartir con tus alumnos por la pizarra.

## Cómo usar:
1. Subí el archivo PDF a esta carpeta (ejemplo: `TP_Mercado.pdf`).
2. En la pizarra del Campus, escribí el nombre del archivo entre corchetes con el prefijo ACT:
   `[ACT: TP_Mercado.pdf]`
3. Los alumnos verán automáticamente un botón premium para descargar el archivo.
